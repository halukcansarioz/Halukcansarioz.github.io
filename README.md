## Installation & Usage

To view the portfolio site locally or inspect the source code, follow the steps below.

**1. Clone the repository:**
```bash
git clone https://github.com/halukcansarioz/halukcansarioz.github.io.git
```

**2. Navigate to the folder:**
```bash
cd halukcansarioz.github.io
```

**3. View the site:**
Because it is a static HTML/CSS/JS site, no dependencies are required:
```bash
open index.html
```
or simply double‑click `index.html` to open it in your browser. You can also use the VS Code Live Server extension.
