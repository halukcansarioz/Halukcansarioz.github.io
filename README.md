## 🚀 Getting Started

If you want to view the source code or run this portfolio locally on your machine, follow these steps:

### Installation

1.  **Clone the repository:**
    
    ```bash
    git clone [https://github.com/halukcansarioz/halukcansarioz.github.io.git](https://github.com/halukcansarioz/halukcansarioz.github.io.git)
    ```

2.  **Navigate to the project directory:**

    ```bash
    cd halukcansarioz.github.io
    ```

3.  **Run the website:**
    *   If it is a static HTML/CSS/JS site, simply double-click the `index.html` file to open it in your browser.
    *   If it uses a framework like React or a static site generator (like Jekyll), run the respective start commands (e.g., `npm install` and `npm start`).
