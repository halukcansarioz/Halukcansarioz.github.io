## Kurulum ve Kullanım

Portfolyo sitesini yerel makinenizde görüntülemek veya kaynak kodunu incelemek için aşağıdaki adımları takip edebilirsiniz:

### 1. Depoyu Klonlayın
```bash
git clone https://github.com/halukcansarioz/halukcansarioz.github.io.git
```

### 2. Proje Dizinine Gidin
```bash
cd halukcansarioz.github.io
```

### 3. Siteyi Görüntüleyin
Statik bir HTML/CSS/JS sitesi olduğu için herhangi bir bağımlılık yüklemenize gerek yoktur:
```bash
open index.html
```
veya `index.html` dosyasına çift tıklayarak doğrudan tarayıcınızda açabilirsiniz.

Alternatif olarak VS Code Live Server eklentisi ile de çalıştırabilirsiniz.

## Katkıda Bulunma
Bu kişisel bir portfolyo projesi olsa da kod, tasarım veya erişilebilirlik konusundaki geri bildirimleriniz her zaman memnuniyetle karşılanır! Bir hata fark ederseniz veya öneriniz varsa issue açmaktan çekinmeyin.

1. Bu depoyu **Fork**'layın.
2. Bir **Branch** oluşturun (`git checkout -b feature/YeniOzellik`).
3. Değişikliklerinizi **Commit** edin (`git commit -m 'Ekleme: Yeni özellik'`).
4. Kodlarınızı **Push**'layın (`git push origin feature/YeniOzellik`).
5. Bir **Pull Request** açın.
